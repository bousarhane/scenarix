# Scenarix Lighting v0.6.23

تطبيق مستقل لتصميم الإضاءة المسرحية، وضبط الأجهزة، وإنشاء الحالات الضوئية ومعاينتها.
صاحب المشروع: **بوسرحان الزيتوني**. هذه نسخة منفصلة مشتقة من فضاء الإضاءة في PREVUSCENE.

## التشغيل

فك ضغط الحزمة كاملة وافتح `index.html` في Chrome أو Edge حديث.
أدخل عنوان العرض واسم المصمم والقاعة، ثم اضغط «دخول مساحة العمل».
يمكن أيضًا فتح ملف إضاءة JSON من شاشة البداية. لا تحتاج إلى تثبيت تطبيق الإخراج أو تسجيل الدخول إليه.

للتطوير أو التثبيت كتطبيق ويب، استعمل Node.js وشغّل `npm run serve` من مجلد الحزمة.
يفتح الخادم المحلي على المنفذ 8080. بعد التحميل الأول تعمل ملفات التطبيق والمعاينة دون اتصال.
يمكن تخصيص المنفذ عبر متغير `PORT`.

## توزيع الواجهة

- **الهيدر:** عنوان العرض، المصمم، الفرقة، القاعة، المرجع الحالي، الحفظ وMENU.
- **MENU:** إنشاء المشروع وفتحه، معلوماته، تصدير JSON/PNG/PDF، إعدادات الخشبة والبارات والطبقات، توسيع المعاينة والتعريف بالتطبيق.
- **بجانب الخشبة:** مكتبة الأجهزة، خصائص الجهاز المحدد، لوحة التشغيل، أدوات الرسم والحالات الضوئية.
- **الكونسول:** تشغيل الأجهزة وإطفاؤها، منزلق شدة لكل جهاز، مجموعات، شدة عامة وBlackout.
- **المعاينة:** مخطط 2D ومعاينة 3D مع أزرار تشغيل وإيقاف مؤقت وعودة للبداية. تعمل دون مرجع إخراج.

اسحب الجهاز من المكتبة إلى الخشبة، ثم حدد جهازًا لضبط اللون والتوجيه والارتفاع.
من «الحالات الضوئية» اضبط الحالة ووقت بدايتها والانتقالات ثم احفظها.
اعتماد الإضاءة الحالية كبداية يحفظ الحالة السابقة لأول Cue.

## الحفظ

«حفظ» يحتفظ بالمشروع داخل المتصفح؛ «تصدير JSON» ينشئ ملفًا مستقلًا قابلاً للنقل والاستيراد.
يشمل الملف الأجهزة والمجموعات والحالات والإضاءة الأولية والمرجع الاختياري.
مفاتيح الحفظ وذاكرة التطبيق دون اتصال مستقلة عن تطبيق الإخراج.
ملفات الإضاءة JSON والحفظ المحلي غير مشفرين.

## مرجع إخراج اختياري

من MENU استورد مشروع إخراج بصيغة JSON أو stage2d **غير مشفر**.
يظهر المرجع للمعاينة فقط؛ يمكن توجيه الضوء نحو ممثل ومتابعة حركته.
يُحفظ المرجع في ملف الإضاءة نفسه، وتُحفظ خطة مستقلة لكل مشهد.
استيراد المرجع يحتفظ بخطة الإضاءة الحالية للمشهد الأول المختار.
«إزالة المرجع» يحتفظ بخطة الإضاءة ويعيد إتاحة تعديل أبعاد الخشبة.
يوجد مثال في `examples/reference-scene.stage2d`.

## المصدر والتطوير

- `app/`: تطبيق الإضاءة وواجهته وكونسوله.
- `preview/`: محرك معاينة داخلي وموارده؛ لا يحتوي على تطبيق إخراج مستقل.
- `shared/`: حساب توقيت الإضاءة، صيغة المرجع وتنظيم الواجهة.
- `tests/standalone.cjs`: اختبار تفاعلي للتشغيل والحفظ والمعاينة والعمل دون اتصال.

لتشغيل الاختبار على بيئة تطوير:

```sh
npm install
npx playwright install chromium
npm test
```

بعد إضافة مورد ثابت، حدّث قائمة التخزين بواسطة `node scripts/build-cache.cjs`.

الحزمة الحالية ملفات مصدر تعمل في المتصفح. توجد نقطة تشغيل Electron وأوامر بناء:
`npm start` و`npm run dist:win` و`npm run dist:mac`.
لم تُنتج أو تُختبر مثبتات Windows أو macOS ضمن هذا التسليم.

تحتفظ المكتبة الحالية بـ19 نموذج جهاز؛ لم تُضف مكتبة تجارية جديدة في هذه المرحلة.
Patch/DMX يخص تنظيم العناوين والقنوات؛ لا يرسل التطبيق الحالي خرجًا إلى أجهزة فعلية.
ترخيص Three.js مرفق في `preview/assets/vendor/THREE-LICENSE.txt`.
